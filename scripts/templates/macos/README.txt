========================================================================
  VTT-ZERO Tabletop Map Projector (macOS Portable Edition)
========================================================================

QUICK START:
1. Double click "start-dual-screen.command" to open both DM Console and Projector window.
   OR double click "launch-dm.command" for DM view.
   OR double click "launch-projector.command" for Player/Projector view.
   (If macOS asks for permission, right click -> Open, or run 'chmod +x *.command')

2. Move the Player View window to your secondary display / TV / Projector.
   Press Control + Command + F (or click the fullscreen button) for Fullscreen.

3. Drag & drop map files (JPG, PNG, WebP, MP4, WebM) into the DM window.
   Use fog tools (Reveal [R], Hide [H], Pan [Space], Grid, Zoom).
   Everything synchronizes to the projector with 0-latency via BroadcastChannel!

NO INSTALLATION OR INTERNET REQUIRED. 100% OFFLINE.
========================================================================
