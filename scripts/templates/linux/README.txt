========================================================================
  VTT-ZERO Tabletop Map Projector (Linux Portable Edition)
========================================================================

QUICK START:
1. Make sure scripts are executable (if needed):
   chmod +x *.sh

2. Run:
   ./start-dual-screen.sh   -> Opens both DM Console and Projector window.
   ./launch-dm.sh           -> Opens DM Console.
   ./launch-projector.sh    -> Opens clean Projector view.

3. Move the Projector window to your second monitor/TV/projector.
   Press F11 for Fullscreen.

4. On the DM window, drop your map image (JPG, PNG, WebP) or video (MP4, WebM).
   Control fog of war, grid, and zoom in real time.

NO DEPENDENCIES OR INSTALLATION REQUIRED. 100% OFFLINE.
========================================================================
